# Gafori Studio — Android APK project

این پوشه سورس برنامه و تنظیمات ساخت APK را دارد. این ZIP خودش APK نصب‌شدنی نیست.

## ساخت APK با GitHub Actions
1. در GitHub یک repository جدید بساز.
2. همه محتویات این پوشه را در repository بارگذاری کن (از جمله پوشه `.github/workflows`).
3. وارد تب **Actions** شو و workflow با نام **Build Gafori Studio APK** را انتخاب کن.
4. گزینه **Run workflow** را بزن و منتظر بمان تا اجرا سبز شود.
5. پایین صفحه اجرا، از بخش **Artifacts** فایل `Gafori-Studio-APK` را دانلود و از حالت ZIP خارج کن.
6. فایل APK را روی گوشی باز و نصب کن. ممکن است Android اجازه نصب از این منبع را بخواهد.

## نکته‌ها
- برنامه با Kivy و Pillow ساخته شده است.
- خروجی‌ها در پوشه `GaforiStudio` در حافظه مشترک ذخیره می‌شوند، اگر دسترسی اندروید اجازه دهد؛ در غیر این صورت در پوشه خصوصی برنامه می‌روند.
- این پروژه در این محیط APK کامپایل نکرده است؛ ساخت نهایی باید در GitHub Actions انجام شود.
